# OpenTTD JGRPP 0.73.4 - 4현시 속도 제어 시험판

## 실행
1. ZIP을 새 폴더에 압축 해제합니다.
2. PLAY-4ASPECT.cmd를 실행하고 새 게임을 만듭니다.
3. 기본 스타일의 전기식 단방향 신호를 설치합니다.
4. 신호 위의 명령 표시등을 봅니다: 적색 정지, 황색 45, 황록색 65, 녹색 선로 허용속도.
5. 긴 단방향 시험선에 신호를 일정 간격으로 놓고 두 열차를 운행합니다. 처음에는 같은 차량과 충분한 신호 간격으로 시작하십시오.

기본 신호 머리의 원래 적/녹 표시는 JGR 진로 예약 표시입니다. 위쪽에 추가한 색상 표시등이 시험판의 속도 명령이며, 황록색은 황색과 녹색 두 표시등입니다. 정식 4등식 신호 그림은 후속 작업입니다.
45/65는 OpenTTD의 km/h-ish 내부 속도 기준으로 통상 미터법 화면에서 약 45/65km/h입니다.

## 설정
게임 설정 → 차량 → 물리 → 현실적 열차 제동을 켭니다.
같은 화면의 '시험용 4현시 신호 속도 제어'를 켭니다.
전방 확인 현시 제한도 켜고 자동 열차 속도 적응은 끄는 것이 시험에 적합합니다.
포함된 실행 파일과 설정은 이 조합으로 새 게임을 시작합니다.

기존 저장게임은 반드시 사본으로 사용하십시오. 저장게임의 설정이 실행 설정을 덮어씁니다.
모든 열차를 정지한 뒤 다음 콘솔 명령으로 설정할 수도 있습니다:
set vehicle.train_braking_model 1
set vehicle.four_aspect_signalling true
set vehicle.realistic_braking_aspect_limited 1
set vehicle.train_speed_adaptation false
현실적 제동은 양방향 신호 및 사전 신호를 허용하지 않습니다. 먼저 기존 게임의 신호 호환성을 확인하십시오.

## 동작과 범위
- 통과한 신호의 속도 명령을 다음 신호까지 유지합니다.
- 전방 신호는 캐시된 색이 아니라 현재 현시를 읽고 제동 곡선으로 접근합니다.
- 자기 열차가 지나간 신호를 적색으로 바꿔도 자기 명령을 적색으로 덮어쓰지 않습니다.
- 독립적인 새 고정폐색 엔진은 아직 없습니다. 기존 JGR의 예약·현시 전파·후미 해제·충돌 방지·역 정차가 유지되므로 예약 상태가 감속에 영향을 줄 수 있습니다.
- 기본 스타일 전기식 Block/Path/PathOneWay 신호가 대상입니다. 다른 NewGRF 스타일, 입환 신호, 교량/터널 가상 신호는 기존 JGR 제어를 사용합니다.
- 4현시로 수송 능력 증가나 흑자를 보장하지 않습니다. 화물 정산과 시설 이용료는 수정하지 않았습니다.
- 신호 변경은 모든 열차가 정지한 상태에서만 허용합니다. 설정 변경 시 기존 속도 명령을 초기화하고 예약 정보를 다시 만듭니다.
- 새 속도 명령과 전방 신호 참조는 저장됩니다. 시험판 저장파일은 원본 JGRPP와 호환되지 않습니다. 모든 멀티플레이 참여자는 같은 시험판 빌드를 사용해야 합니다.

## 검증
자동 빌드는 실제 게임 전체와 openttd_test를 컴파일하고 CTest를 실행합니다.
단위검사는 현시 명령 전환과 적색을 진입 허가로 받아들이지 않는 동작을 확인합니다.
이 검사는 실제 장시간 운행, 분기기, 저장게임 복원, 멀티플레이 동기화의 완료 검증을 대신하지 않습니다.
원본 저장파일을 덮어쓰지 말고 먼저 새 시험선에서 운행하십시오.
